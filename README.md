# DungeonGenerator2

This is a simplification of an older dungeon generator I created a while ago. The overarching purpose of the original is to have a dungeon generator that would reward players for exploring the pathways of a dungeon. This contrasts with typical dungeon generator design, which would randomly spawn items indiscriminately from room to room.

To do this, graphs are utilized to determine depth from a starting room. Based off depth, priority for certain objects can be generated.
